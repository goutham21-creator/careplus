# CarePlus Hospital Website

Professional Hospital Management Website built with HTML, CSS, JavaScript, and Firebase.

## Features
- **Responsive UI**: Apple-inspired design with animations.
- **Departments & Services**: Informative pages with grid layouts.
- **Doctor Search**: Filter by specialization.
- **Appointment Booking**: Integrated with Firebase Firestore.
- **Contact Form**: Functional inquiry form (Firestore).
- **Admin Access**: Hidden admin login (`Ctrl + Shift + L`) to view appointments.

## Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JS.
- **Backend**: Firebase Auth, Firebase Firestore.

## Usage
1. Open `index.html`.
2. Navigate through pages using the header.
3. Access Admin Panel using `Ctrl + Shift + L`.
   - **Email**: `admin@careplus.com`

## Deployment
This project is ready for deployment on [Vercel](https://vercel.com).
Simply import this repository and Vercel will automatically detect the static configuration.
